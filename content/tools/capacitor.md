I’ve worked with CapacitorJS to build cross-platform mobile applications using web technologies. Integrating native device features like camera, geolocation, and file storage, I’ve optimized performance while maintaining a smooth user experience. I’ve also developed custom Capacitor plugins, such as integrating Sensor.TYPE_ROTATION_VECTOR for a Quasar + Capacitor project, ensuring seamless interaction between web and native layers.
