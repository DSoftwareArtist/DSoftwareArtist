# Mapbox

I’ve worked extensively with Mapbox, developing high-performance, interactive maps with custom styling and real-time geospatial data visualization. By leveraging Mapbox GL JS, I’ve built immersive 3D maps, optimized route planning applications, and integrated geolocation services for various industries, from logistics to tourism. I’ve also optimized rendering efficiency and API usage to handle high-traffic applications.
