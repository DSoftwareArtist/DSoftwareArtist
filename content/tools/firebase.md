I’ve worked with Firebase for real-time database management, authentication, and cloud functions. Leveraging Firebase Firestore and Realtime Database, I’ve built applications with instant data synchronization. I’ve also integrated Firebase Authentication for secure user sign-ins and used Firebase Cloud Messaging (FCM) for real-time push notifications in web and mobile applications.
