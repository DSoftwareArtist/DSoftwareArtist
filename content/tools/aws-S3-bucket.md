# AWS - S3 Bucket

I've used AWS S3 extensively for storing and managing static assets, backups, and media files in web applications. Whether integrating it with Django for handling file uploads or serving assets in a Vue.js or React app, I’ve optimized configurations for security, performance, and cost efficiency. I’ve set up fine-grained access controls using IAM policies, enabled versioning for data integrity, and used lifecycle rules to manage storage costs. Additionally, I’ve leveraged S3 with CloudFront for content delivery, ensuring fast and reliable asset distribution. My experience with S3 has been crucial in building scalable and resilient applications.
