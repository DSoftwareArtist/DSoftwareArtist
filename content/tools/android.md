# Android

I’ve worked with Android development, integrating native features and optimizing performance for smooth user experiences. My experience includes working with Java and Kotlin, as well as integrating Android with web technologies using frameworks like Quasar and Capacitor. I’ve developed and customized Android plugins, such as implementing a custom Sensor.TYPE_ROTATION_VECTOR plugin to enhance functionality. I focus on optimizing app performance, ensuring efficient resource management, and maintaining a seamless UI/UX across different devices. Sharing my experience, I enjoy helping others understand best practices in Android development, from debugging to implementing platform-specific features.
